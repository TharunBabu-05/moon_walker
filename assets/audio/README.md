# SELENE sound assets

The `.ogg` recordings in this folder are by **Kenney**, licensed **CC0 1.0** (public domain dedication). Original licence files are included.

- [Impact Sounds 1.0](https://kenney.nl/assets/impact-sounds): `footstep_*`, `impact*`.
- [Interface Sounds 1.0](https://kenney.nl/assets/interface-sounds): `click_001`, `confirmation_001`, `switch_001`, `error_001`.

Downloaded from Kenney on 2026-10-27. A small selection is bundled locally; no runtime third-party audio requests are needed. Snow/crunch recordings are repurposed as fictional regolith foley. The suit airflow, rover motor, and aiming tone are generated in `src/audio.js` for SELENE. This is cinematic feedback heard through a suit, not a simulation of sound propagating through lunar vacuum.
